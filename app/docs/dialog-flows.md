## 弹窗步骤合并

> ⚠️ 这一节名是指针锚点（`src/ui/AGENTS.md` 指过来，`docAnchors.test.js` 核它在）——**别改标题**。

### 已合并（`v9.3.5`）

| 流程 | 改前 | 改后 |
|---|---|---|
| **添加根节点**（`G4_add.js:promptAddRoot`） | 选类型 → prompt 名称 → prompt 链接（**三步**） | 选类型 → **一个表单**（名称 + 链接） |
| **添加子节点 W/S**（`showAddChildForm`） | prompt 名称 → prompt 链接（**三步**，与上面同一套拆法复制了两处） | 选类型 → **一个表单**（名称 + 链接） |
| **添加子节点 C（比赛）** | prompt「请输入比赛名称」→ 表单（**里面又有 name 字段**） | **一个表单**（名称 + 链接 + 比赛时间） |
| = 实现 | —— | **一份** `G4_add.js:addNodeForm(title, {nameDefault, extraFields}, done)`（根 / W-S / C 共用；名称非空走**关框前**校验） |

R / P 本来就是单表单；合成节点那条链本来就是"问一句 + 一个表单"，都没动。

### **不合并**的（清点过，别以后再来"顺手并一下"）

| 流程 | 为什么不并 |
|---|---|
| **选类型**（`showTypeSelector`）→ 表单 | 它**分支到不同的表单**（R / P / C / W-S 字段完全不同）；并掉就得先知道类型才画得出字段 |
| **「标记为合成节点？」**（`G4_add.js:askSynthOption`）→ 合成表单 | 它也是一个**分支**（勾了走 `createSynthNode`、否则走 `addChild`），而且带着一段**解释**（"合成节点在树上就是个普通节点…"）+ W/S/O 的**禁用理由**。并进表单的三个前提：① `renderEditFieldsHtml`（`G2_common.js`）只支持 text/select ⇒ 要**先给它加 `type:'checkbox'`**；② 还得能"勾了才显示合成标识"（动态字段，今天只有 select 依赖那套）；③ 那段解释要跟着搬。**代价大于收益**，留着 |
| **复制到副页**（`G4_copy.js:promptCopyToPage`） | 第二步是"**选另一个对象**"（目标父节点，`showTreeSelector`）；而且没有父节点时那一步会被**跳过** |
| **编辑节点 / 编辑提交** → `confirmAnomalies` | 第二步是**异常 / 破坏性确认**（"同名同号"警告），不是问字段 |
| **批量设置比赛状态**（`G5_actions.js`） | 选完"忽略/恢复"后那次确认**按选择分支到两种文案**，且是破坏性的 |
| **待办题单 / 按条件挑题**（`G5_todoSheet.js`） | ①那一个弹窗**已经把该并的都并了**（条件 + 目标副页 + 当场新建副页）；②只在冲突时出现（确认框）。**正面样板** |
| **账户管理 → 编辑账户 / 重跑归认确认**（`G8_accounts.js`） | "列表 → 单条编辑" + 一次确认，分属不同层 |
| **映射弹窗 → 导入冲突确认**（`G3_mapping.js` / `H2_batchImport.js`） | 同"确认框"那一类 |
| **选目标（编辑哪个 / 看哪个 / 选副页树）**（`G7_*`） | 选完**分支到不同落点**（详页 / 编辑器 / 树定位） |
| 各种 `*WithConfirm`（重置 / 清空 / 删计划 / 删副页…） | 一律是"一个动作 + 一次破坏性确认"，标准二段 |

**判据（一句话）**：要看"后一步"是不是**同一个对象的又一个字段**。是 ⇒ 并；
是"选另一个对象 / 确认破坏性操作 / 按上一步结果分支" ⇒ **不并**。

### 「同一信息被问两遍」清单（并了或结案）

| 信息 | 情况 | 结果 |
|---|---|---|
| C 的比赛名 | prompt 问一次 → 表单里 `name` **又问一次** | ✅ 已并（`v9.3.5`） |
| 节点「名称 + 链接」 | 根节点与 W/S 子节点**各写了一套**两步拆法 | ✅ 并成一个表单 + **共用一个** `addNodeForm` |
| 「选一个副页」 | `G4_copy.js`（复制到副页）与 `G5_todoSheet.js`（挑题建页）**各写一份 `<select>` 副页列表** | ✅ **已收成一份**（`v9.3.6`）：`ui/kit/pagePicker.js` —— 列表 / 计数口径 / 选项文本 / 「＋ 新建副页」哨兵 / 显示隐藏 / 读回校验全在一处；连页签栏那份列表（`G_pageUI.js`）也改用同一份（原来"这一页几个节点"三处各写一遍，其中一处还少了 `max(0, …)`） |
| 性质三字段（分类/年/季/地区） | 判重整理行内点性质、与题目编辑弹窗，**两个入口分别问** | ✅ 结案：两个入口本来就该各自能改；字段描述符**同源**（`natureFieldDescriptors` / `buildEditForm`），没分叉 |
| 合成标识 | 新建时填、事后在判重页改 | ✅ 结案：两处入口不同（建 vs 改），校验都在 `core/ops/synth.js` 那一份里 |
