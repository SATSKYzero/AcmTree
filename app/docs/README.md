# 文档地图（docs/ 里每份管什么）

> **这份是入口，不是正文。** 找东西先看这张表，别一份份翻。
>
> 📌 **受众**：除 `guide.html`（写给**用应用的人**，应用里也有「📖 指南」按钮）之外，
> 本目录其余文档都是**给接数据 / 跑数据流水线的人**看的。
>
> 一个规矩：**一份文档只有一个职责**；同一个口径**只住一处**，别处只给指针（"见 X"），不抄第二份。

---

## 一、我该读哪份

| 我想…… | 读这份 |
|---|---|
| **用起来**（导入数据 / 补题 / 看统计 / 出问题怎么查） | `guide.html`（应用内右上角「📖 指南」按钮打开） |
| **一口气讲清整个系统**（两分钟版） | `架构一页.md` |
| **判断一个字段该不该有 / 值凭什么 / 冲突听谁的** | `field-rules.md` |
| **写爬虫接进来**（适配器契约、一条命令跑通） | `scraper-guide.md` |
| **改导入包 / 合并语义**（crate 契约、查重、指针） | `auto-import.md` |
| **跑测试 / 写测试** | [`如何使用test.md`](如何使用test.md)（命令本身看 `package.json` 的 scripts） |
| **走一轮数据维护**（哪几步必须人动手、怎么核对） | `manual-workflow.md` |
| **往年牛客多校要哪些场次、怎么省流量地抓** | `nk-multi-university.md`（⚠️ 完成状态是快照） |
| **动数据流水线本身**（原始数据 / 脚本 / 产物） | [`../acm-data/readme.md`](../acm-data/readme.md) |

## 二、边界（每份**不**管什么）

| 文档 | 只管 | 不管（去别处） |
|---|---|---|
| `guide.html` | 使用者视角：点哪儿、会发生什么、出问题按什么顺序查 | 设计与口径（本目录不管） |
| `架构一页.md` | 全局骨架 + 单一真源清单 + 不变量 | 细节与论证（它是索引，不是正文） |
| `field-rules.md` | 字段的**应有 / 已有 / 来源 / 优先级**：判据与冲突规则 | 代码怎么落地（本目录不管） |
| `manual-workflow.md` | 一轮维护里**人**的步骤与核对点 | 机器判据（`field-rules.md`）、脚本内部（`scraper-guide.md`） |
| `scraper-guide.md` | 给**写爬取脚本的人**：契约、自测、跑通一次导入 | 应用侧怎么显示（`guide.html`） |
| `auto-import.md` | crate 包形状、extKey 查重、合并/指针语义、导入事务 | 字段该不该有（`field-rules.md`） |
| `nk-multi-university.md` | 往年牛客多校：要哪些场次、提交怎么抓、包长什么样 | 通用爬虫写法（`scraper-guide.md`） |

## 四、专题（**横跨几层**的机制与坑 —— 各层的 `AGENTS.md` 都指向这里）

> 上面第一、二节是"**你想干什么 → 读哪份**"；这一节是"**动哪一层之前先看哪份**"。
> 这些篇都不是"某一份文件"的说明，而是**一条机制**或**一族的坑**（所以没有目录可挂）。
> ⚠️ 现状与精确数字**不写进这些篇**（会漂）—— 要写就写"怎么核"。

| 文档 | 管什么（一句话） | 什么时候必须看 |
|---|---|---|
| `value-projection.md` | 值 / 多来源投影 / 范围："当前值"凭什么、账户范围怎么滤 | 动 `core/trust.js`、`core/fieldValue.js`、值级面板 |
| `core-pitfalls.md` | `src/core` 踩过的坑（症状 → 病根 → 判据） | 动 core 层任何东西 |
| `ui-conventions.md` | 界面约定（重画入口 / 视图态 / 弹窗「取消」语义 / 「筛选」的五种主语 / 烟雾桩的边界…） | 动 `src/ui`、写冒烟断言 |
| `dialog-flows.md` | 多步弹窗**要不要合并**（已并的 3 处 + 10 处"不该并"） | 加一个新的多步流程 |
| `subpage-sync.md` | 副页对齐 / 屏蔽 / 仪表盘（副页是**快照**） | 动副页、加全局操作 |
| `subpage-copy.md` | 副页复制（页内 id 必须全部重发、不复制计划） | 动 `G_pageUI.js`、加整页级写操作 |
| `training-plan.md` | 训练计划（题集 / 期与粒度 / 强度曲线 / 各期达成） | 动计划页或 `core/trainingPlan.js` |
| `stats-and-grid.md` | 分档口径 / 状态×难度网格 / 强度热力图 / 账户对比 / 来源 id 的显示 | 动统计页那几块 |
| `node-navigation.md` | 跳转 / 面包屑 / 详页的**现成入口**（都只有一份，别造第二份） | 要让用户"跳到某个节点/打开详页" |
| `node-lists.md` | "一行一个节点"那种列表的三件套（🔎 跳树 / 📋 详页 / 面包屑）+ 迁移顺序 | 加一张节点清单 |
| `ac-time-rule.md` | AC 时间怎么取（三条规则 + 截断值） | 动 AC 时间/`acTimeRule.js` |
| `manual-values.md` | 手改值的归属（客观 / 账户私有；**设计稿**） | 动 `manualScopeOf`、清空/转共用 |
